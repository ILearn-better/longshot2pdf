# LongShot2PDF

把**任意可滚动界面**自动滚动截取、无缝拼接、输出为多页 PDF。

典型场景：在网盘里打开一份 500 多页的 PDF，一次性完整滚下来，存成本地 PDF 文件。

## 为什么不用微信长截图

| 维度 | 微信长截图 | 本项目 |
|---|---|---|
| 输出格式 | 一张超长 PNG | 多页 PDF（A4 比例） |
| 拼接精度 | 固定位移，易跨页断连 | 逐帧重叠匹配，零断连 |
| 超长处理 | 过长会被拉伸失真、有上限 | 流式分页，无长度上限 |
| 清晰度 | 二次编码，文字发虚 | 原始像素，JPEG 4:4:4 |

## 三个核心设计

1. **滚动有效性探测**：点击开始后先实测光标位置是否响应滚轮，不响应就直接告诉你，不会白滚一场。
2. **内容自对齐拼接**：不靠固定位移，用上一帧底部的像素指纹在当前帧里搜索重叠位置，滚动量不均匀也不会错位。
3. **流式分页**：内存里永远只保留不到两页。500 页（约 70 万像素高、整图 RGB 需 2.1GB）不会 OOM。

## 项目结构

```
longshot2pdf/
├── docs/开发文档.md   需求还原、技术方案、注意事项清单、角色分工
├── src/
│   ├── winapi.py      全局滚轮投递 / 光标定位 / DPI 感知
│   ├── capture.py     区域截图
│   ├── probe.py       滚动有效性探测
│   ├── stitch.py      重叠匹配 + 流式拼接分页
│   ├── pdfwriter.py   JPEG 序列 → 多页 PDF
│   └── pipeline.py    编排层
└── tests/test_stitch.py  拼接内核离线验证
```
